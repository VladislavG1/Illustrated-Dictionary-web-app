# Illustrated-Dictionary-web-app

### Веб-приложение иллюстрированного словаря слов русского языка для инофонов

> Сайт для кафедры русского языка как иностранного ЧелГУ, предназначенный для обучения иностранных студентов русскому языку.
Стек технологий: Python + HTML + CSS + JavaScript + Django + Bootstrap + PostgreSQL
